# 從認識到選擇 × 元培食安

元培醫事科技大學食品科學系 USR 計畫的 GitHub Pages 靜態網站版本。

## 網頁內容

- USR 計畫理念與成果數據
- 近期課程資訊
- 食品科普三步小教學
- 食品科學文章
- 活動成果列表與影片連結
- Instagram 與 LINE 官方社群

## GitHub Pages

推送到 `main` 分支後，`.github/workflows/pages.yml` 會自動發布網站。

## 靜態版限制

GitHub Pages 只支援靜態檔案，因此此版本不包含管理後台、資料庫寫入、站內報名及媒體上傳。課程報名與成果影片會連到原網站；完整後台版原始碼需部署至支援 JavaScript 伺服器、資料庫與物件儲存的主機。
